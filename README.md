# Brief-1

Site vitrine en français pour une entreprise de services web. Quatre pages HTML partagent une feuille de style.

[Site vitrine](https://baalla-services-web-demo.abdelhakimbaalla50.workers.dev) · [Page des services](https://github.com/Abdelhakim-Baalla/Brief-1/blob/master/html/services.html)

Pour reconstruire la démo depuis la racine du dépôt, exécuter `python3 scripts/build-demo.py`. À la racine, `npx wrangler deploy` publie les fichiers générés.
